# Yオク新着ウォッチャー — YahooAuctionWatcher

Windows向けのYahoo!オークション新着監視ツールです。キーワードを登録すると、設定した間隔で検索し、新しい出品を通知します。

このリポジトリは無償版の配布・利用案内用です。アプリのソースコードは公開していません。

## ダウンロード

右側の **Releases** から最新版を開き、`YahooAuctionWatcher_free_Setup_v5.9.0_x64.exe` をダウンロードしてください。
「Source code」と表示されるZIPはアプリ本体ではありません。

## 動作環境

- Windows 10 / 11、x64環境
- インターネット接続
- Pythonのインストールは不要です

## 主な機能

- キーワードを指定した定期検索（30・60・120・360分）
- 新着のWindows通知、任意のGmail通知
- 検出履歴の表示、出品ページへのアクセス
- 現在価格・即決価格・入札件数・残り時間の表示
- 選択した商品の画像プレビュー
- 再出品と判定した商品の新着通知抑制
- Windowsサインイン時の自動起動

[有償版をBOOTHで購入する](https://3forzing.booth.pm/items/9117175)。まず無償版で動作をご確認ください。

## 使い方

1. インストーラーを実行して起動します。
2. 監視したいキーワードと確認間隔を登録します。
3. 「今すぐ確認」で動作を確認します。

初回検索は現在の出品を基準として登録し、新着通知は行いません。以降の検索で新たに見つかった出品を通知します。
検索語を空白で区切った場合、すべての語がタイトルに含まれる商品を対象とします。一部の語のみの代替結果は除外します。
アプリが動作し、PCが通信できる状態で定期確認します。常時即時通知を行う仕組みではありません。

## 更新と版の切り替え

トレイアイコンからアプリを完全終了し、新しいインストーラーを上書き実行してください。
設定・履歴は `%USERPROFILE%\YahooAuctionWatcher` に保存されます。
有償版から無償版に切り替えた場合、最初に登録した1件のみ監視します。他の登録・履歴は保持します。

## 問題が起きた場合

「実行ログ」のエラー内容をご確認ください。問い合わせの際は、アプリのバージョン・Windowsのバージョン・再現手順・エラー文を添えてください。
ログや画面を公開する際は、メールアドレスなどの個人情報を除いてください。

Yahoo!オークションのページ変更やアクセス制限などにより、一時的に取得できなくなる場合があります。
